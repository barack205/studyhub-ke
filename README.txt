STUDYHUB KE — PRACTICE QUESTION UPDATE

FILES
- index.html: page structure
- style.css: visual design
- script.js: quiz behaviour and question bank

RUN IT
1. Extract the ZIP folder.
2. Open the folder in VS Code (File > Open Folder).
3. Double-click index.html in File Explorer to open it in your browser.
4. Choose Form 1–4 and a subject. Each quiz now has six questions.

ADD QUESTIONS
1. Open script.js in VS Code.
2. Find const extraQuestionBank near the top of the inserted question section.
3. Pick a Form number and subject (mathematics, biology, chemistry, english).
4. Copy one question object and edit topic, q, options, answer and explanation.
5. The answer field is zero-based: 0 = first option, 1 = second, 2 = third, 3 = fourth.
6. Save script.js and refresh the browser.

CURRICULUM NOTE
Questions are original practice material based on broad revision topics, not official KICD/KCSE exam questions. The Form/topic placements are draft groupings and must be checked against the current curriculum design and schemes of work before claiming exact alignment. Check KICD: https://kicd.ac.ke/cbc-materials/ and Kenya Education Cloud: https://lms.kec.ac.ke/

No installs, packages, database, or internet connection are needed to run the quiz locally.
